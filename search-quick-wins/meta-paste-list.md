# Titles and descriptions to paste (Rank Math)

There are two ways to apply these. Use **one**, not both:
- **By hand**, below: about 2 minutes per post.
- **With the script:** `python3 search-quick-wins/apply_rank_math_meta.py`. It's a dry run unless you add `--apply`.

**To paste by hand:**
1. Open the edit link.
2. Click the Rank Math icon at the top right of the editor, then **Edit Snippet**.
3. Replace the **Title** and **Description** with the text below, exactly as written.
   - Don't add `%sep% %sitename%`; these titles are complete as they are.
   - Leave the WordPress excerpt empty, because on this theme it shows as a subtitle under the post title.
4. Click **Update**.

The 7th item, **Tullahoma**, needs no pasting. Its title and description are in theme code on this branch (`page-location-tullahoma.php`) and go live when the theme is deployed. Leave its Rank Math fields empty.
